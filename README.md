# osp.no

The homepage of OSP Holding AS, served by GitHub Pages at https://www.osp.no.

Plain static files, rendered once from the old Phoenix app in tallakt/osp.no
(which ran on Heroku). Edit the HTML directly; a push to `main` publishes it.

- `/` – `index.html`
- `/employees/tallak` – `employees/tallak.html`
- `/1` – short link to the page above (`1/index.html`)
